# Cert900 educational work

For study guides, Study Hub instruction, lessons, diagrams, knowledge checks,
walkthroughs, course material, video/animation scripts and transcripts, follow
[the educational content standard](docs/educational-content-standard.md).

Teach beginners progressively. Define terms before using them, use short connected
explanations and concrete examples, and preserve technical coverage with a written
before/after map. Passing tests does not establish instructional quality: inspect
the actual mobile reading experience and request the owner's educational review.

Read `CLAUDE.md` for existing project conventions. User authorization and scope
take priority. A content task does not authorize question-bank, scoring, session,
authentication, progress, consent, advertising or production changes. Preserve
existing worktrees. Never read credential files or reveal secrets.
