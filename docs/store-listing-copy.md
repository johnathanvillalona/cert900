# cert900 mobile — store listing copy (ready to paste)

Describes what the app does today: seven certification banks (CompTIA A+,
Network+, Security+; AWS Cloud and AI Practitioner; Azure Fundamentals), timed
full-exam mode and adaptive drills, performance-based questions in each vendor's
format, a spaced-repetition review queue, a readiness estimate, offline use,
on-device progress, per-question free video links, and optional Google or Apple
sign-in for sync.

Never name a feature as missing, "coming soon", or "on the roadmap", and never
point a reader at the website for something the app cannot do. Apple reads the
first as a beta submission (Guideline 2.1) and the second as an app that should
have been a web page (Guideline 4.2). If a capability is not ready, say nothing
about it.

Trademarks (CompTIA, AWS, Azure) are kept out of the app **name** and used only
descriptively in the subtitle, keywords, and body, where nominative use is
standard and both stores are permissive. cert900 is independent and unaffiliated.

Character counts are exact (spaces included) and within each field's limit.

Anyone studying for a CompTIA, AWS, or Azure certification who wants honest, no-cost practice that mirrors the real scoring and points straight to trusted video explanations.
